# Ayushman Sahu — Portfolio

A responsive, Harry Potter-inspired portfolio with an original moonlit-castle illustration, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. For example:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The site has no build step or package dependencies. Google Fonts are optional; system serif and sans-serif fonts provide offline fallbacks.
